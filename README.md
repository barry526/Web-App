二、 規格文字說明：
【專案名稱】
黃光設備：晶圓重洗與防破片挑戰 (Wafer Rework & Strip Wet Bench Simulator)

【專案概述】
本專案結合機械工程與半導體濕製程（Wet Bench）背景，設計一款考驗即時分類與手速控制的網頁小遊戲。玩家扮演無塵室設備工程師，在產線送來需重工的晶圓時進行正確的化學槽清洗，同時必須注意操作手速，避免機械手臂夾碎晶圓。

【核心功能與互動邏輯】
1. 動態晶圓缺陷與化學槽分類：
   - 系統隨機生成帶有「光阻殘留」、「表面微塵」或「嚴重刮傷」的晶圓狀態。
   - 玩家需對應點擊三大清洗槽（去光阻槽、純水沖洗槽、直接報廢）。
2. 防手殘破片機制 (Anti-Breakage Cooldown)：
   - 模擬真實無塵室中因急躁操作導致機械手臂夾碎晶圓的狀況。若點擊過快（小於 0.4 秒連續點擊），會觸發破片懲罰並重扣良率。
3. 限時挑戰與結算評價：
   - 35 秒倒數結束後，依據最終處理的晶圓數量與良率給予專屬的工程師職稱評價。

【技術架構】
- 採用單一 index.html 檔案實作（HTML5 + CSS3 Flexbox 佈局 + 原生 JavaScript 狀態計時與防呆點擊演算法）。
- 部署於 GitHub Pages，支援跨平台瀏覽器直接遊玩。
